# MedAgent - 评测输出目录

## 概述

本目录存放 MedAgent 项目的最新评测输出数据，包括 1,000 条全量评测结果、统计信息和可视化图表。

| `model_stats_*.json` | 各模型统计信息 (1,000 条) |
