## 关键贡献点

### 1. 统一工具交互框架
- 将医院环境所有交互定义为格式统一的工具函数
- 标准化的输入输出接口
- 可控信息访问机制

### 2. 大规模合成数据管线
- 四阶段生成管线（生成 → 审查 → 重写 → 评判）
- 从 9 个科室的 177,703 条种子病例中生成 6,951+ 条高质量病例
- 多 GPU 并行处理，断点续跑

### 3. 智能体强化学习训练
- 基于 GRPO 的训练框架
- 自定义奖励函数（诊断、治疗、效率、成本）
- LoRA 参数高效微调

### 4. 全面基准评测
- 9 个前沿大模型在 1,000 条病例上的评测
- 三维度评分（诊断、治疗、安全性）
- 效率与成本分析

### 5. 关键词知识检索
- 纯关键词匹配替代 embedding+reranker RAG
- 零延迟、无外部服务依赖
